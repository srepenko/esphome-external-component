# gsl3680 — тачскрин GSL3680 (ESP32-P4, JC8012P4A1)

Драйвер сенсорного екрана GSL3680 для ESPHome.

## Що змінено

У базовій версії сенсор читався лише з основного циклу ESPHome. Коли цикл зайнятий (наприклад, виведенням відео), короткий дотик встигав початися й закінчитися між двома читаннями й губився. Тому кнопки спрацьовували «не з першого разу».

Тепер:
- переривання сенсора будить окрему задачу FreeRTOS (`gsl_touch`, ядро 1), яка одразу читає дані по I2C;
- поки палець на екрані, задача опитує сенсор кожні 30 мс, щоб не пропустити відпускання;
- кожне натискання фіксується: навіть дуже коротке віддається LVGL і `on_touch` щонайменше 60 мс, і LVGL встигає його побачити;
- основний цикл лише забирає зафіксований стан.

## Використання

```yaml
touchscreen:
  - platform: gsl3680
    id: my_touchscreen
    reset_pin: GPIO22
    interrupt_pin: GPIO21
    transform:
      mirror_x: true
```
