# panel_motion — детектор руху за вбудованою камерою ESP32-P4

Будить екран настінної панелі, коли перед нею хтось є. Працює з кадрами `esp_video_camera`.

- Кадр ділиться на сітку клітинок; кожна порівнюється з кадром ~1 с тому.
- Поріг клітинки залежить від підсилення сенсора (gain). У темряві шум більший, тому й поріг вищий.
- Рух зараховується після 2 послідовних спрацювань.
- Своя автоекспозиція (крок 0.30).
- Раз на 5 с пише діагностику в лог: середня яскравість, експозиція, gain.
